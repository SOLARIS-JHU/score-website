# SCORE paper website

Project page for **SCORE: Statistical Certification of Regions of Attraction via Extreme Value Theory** by Pietro Zanotta, Panos Stinis, and Ján Drgoňa.

- Paper: https://arxiv.org/abs/2603.29658
- Code: https://github.com/SOLARIS-JHU/SCORE

The site is a static HTML/CSS/JavaScript project and can be served from any static host, including GitHub Pages.
